<h1>Q&A</h1>
<h2>what is Theca?</h2>
Theca is a website meant to (theoretically) replace/supplement the Hack Club Guides Page.
<h2> who's it for? </h2>
Theca is for everyone to use! Specifically though, it's meant to be a place that hack clubbers can learn from, and - if I figure out how to add the feature in a good way - a place for hack clubbers to post their own guides!
<h2> how much effort will it take to build this? </h2> <!-- Probably best to remove this question later on and replace it with "how much effort DID it take to build this?" -->
Project Theca will take quite some effort as I need to learn how to make a website, and all the things that come with and after making one (and since a potential goal is for other people to be able to add their own guides, it could potentially be infinite effort since it'll keep being added to :).
<h2> what do i need to learn to make this happen? </h2> <!-- Probably replace later on with "what DID I have to learn to make this happen -->
I need to learn how to make basic website using VScode. After that I'll need to know how to add onto it and make it better (which I imagine is what the bulk of my time spent on this project will be).

<h2> How to use Theca</h2>
1. Go to [Theca](https://theca-5psigebk3-mv-7df2.vercel.app/)
2. Explore the site
3. To find guides (real ones will be added in future) go to guides tab to browse
4. If you're looking for something specific, go to the tags tab (more tags/customized ones will be added in future)
